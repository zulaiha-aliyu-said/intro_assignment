CapCutMini is a lightweight Android video editor built with Kotlin, Jetpack Compose, and Media3. Pick multiple clips, trim, fade, add audio and subtitles, then export an MP4 — without accounts or cloud lock-in.

Features

Multi-clip timeline

Select several videos in one session, stage thumbnails, reorder clips, and keep your edit order for export.

Videos browser

Browse device videos in a scrollable grid, or open folders through the system picker with scoped storage permissions.

Add Audio

Attach MP3, WAV, or M4A tracks with trim, volume, and start offset — mixed into the exported MP4 with your clip audio.

Effects & export

Fades, transitions, trim, manual subtitles, ExoPlayer preview, and Media3 Transformer MP4 export — all on-device.

Install on Android

  1. Tap Download APK on this page (or open the GitHub Release asset).
  2. If Android blocks the install, open the notification or Settings → Apps → Special access → Install unknown apps and allow your browser or Files app once.
  3. Open the downloaded .apk and tap Install.
  4. Future updates: install the newer CapCutMini APK over this one. Keep the same app ID (com.capcutmini.app) and the same release signing key — no uninstall required.

Tip: uninstalling deletes local projects. Prefer updating over the existing install.
